# Random Quote Generator

A simple and interactive random quote generator app built using HTML, CSS, and JavaScript. Each time the user clicks the "New Quote" button, a random quote is displayed. The app is designed with smooth animations and a clean, modern UI for a pleasant user experience.

---

## Features
- Click the "New Quote" button to display a new random quote.
- Smooth animation transitions for displaying quotes.
- Clean and responsive UI.
- Built with HTML, CSS, and JavaScript.

---

## Technologies Used
- **HTML** for the structure and content of the app.
- **CSS** for styling and animations.
- **JavaScript** for dynamic quote generation and button functionality.

---

## Usage
Click the "New Quote" button to generate a random quote.
Quotes will change each time the button is pressed.
